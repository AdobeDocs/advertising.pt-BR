# [!UICONTROL Asset Report]

*Aplicável a campanhas habilitadas para [!DNL AI Max] somente em [!DNL Google Ads] contas*

O [!UICONTROL Asset Report] inclui dados de conversão de custo, clique e (opcionalmente) [!DNL Google] rastreados no nível do ativo para cada ativo gerado pela IA aplicável em campanhas habilitadas para [!DNL AI Max]. O relatório não inclui conversões do Adobe Analytics. Use este relatório para priorizar quais ativos manter, pausar ou substituir.<!-- Not included as of 7/22/26: You can optionally include advertiser-specific label classifications. -->

Por padrão, os dados incluem uma linha para cada ativo aplicável (como logotipo, imagem, vídeo ou título) com pelo menos uma métrica rastreada para cada unidade de tempo no intervalo de datas especificado. As linhas estão em ordem crescente pelo nome da campanha por padrão.

Os dados de [!DNL Google Ads] normalmente estão disponíveis nos últimos 36 meses.
